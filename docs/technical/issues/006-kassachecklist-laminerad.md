# KASSACHECKLISTA — 1 SIDA, SKRIV UT OCH LAMINERA

## ✔ FORTSÄTT SÄLJA

### 🟢 Grön status
- Allt OK.
- Fortsätt registrera köp.

### 🟡 Gul status
- Nätproblem.
- Köp sparas ändå lokalt.
- Fortsätt sälja.

### ⚠ Offline / degraderat läge
- Kassan fungerar fortfarande.
- Köp sparas lokalt.
- Fortsätt sälja.

> **Huvudregel:**
> Så länge du INTE ser ett kritiskt filfel ska du fortsätta knappa in köp.

## 🔴 STOPPA DIREKT

Om du ser något av detta:

- "Fel vid skrivning till kassafil"
- "Problem med filrättigheter"
- "Kunde inte skapa kataloger"

Gör då detta direkt:

1. Sluta använda datorn.
2. Rör inget mer.
3. Kontakta ansvarig.
4. Byt dator.

## ✔ INNAN DATORN STÄNGS AV

Kontrollera ALLTID detta:

- Inget "Väntar på uppladdning (N)"
- Ingen röd prick
- Alla köp är slutförda

Om något finns kvar:

- Vänta
- Åtgärda
- Stäng inte datorn än

## 🔴 RÖD PRICK

- Klicka på den röda pricken.
- Rätta det som är fel.

Vanligast:

- Fel säljnummer → ändra och spara
- Duplicate receipt → ignorera

## ✔ MINI-FLÖDE

- Säljnummer → `TAB`
- Pris → `ENTER`
- Betalning → slutför köp

## ⚡ SAMMANFATTNING

> 🟢 / 🟡 = Fortsätt sälja  
> 🔴 = Åtgärda innan du går vidare  
> ⚠ Filfel = Stoppa direkt och byt dator  
> ✔ Innan stängning = inga väntande poster
